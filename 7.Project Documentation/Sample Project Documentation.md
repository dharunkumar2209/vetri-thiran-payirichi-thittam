## 5. Risks and Limitations

| S.No | Risk / Limitation                        | Mitigation                                                                                 |
| ---- | ---------------------------------------- | ------------------------------------------------------------------------------------------ |
| 1    | AI output may contain legal inaccuracies | Disclaimer on every document; user edit step; recommend lawyer review for high-value cases |
| 2    | Laws differ by region                    | Jurisdiction field in form; templates reviewed per region                                  |
| 3    | AI service downtime                      | Error handling and retry option                                                            |
| 4    | Sensitive personal data                  | Authentication, owner-only access, no third-party sharing                                  |
